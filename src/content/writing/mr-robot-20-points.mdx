```bash
cat mr.robot.gif
```

<Image
  src={ss2}

Үүсгэсэн key-ийг gpg дээр импорт хийнэ.

```bash
gpg --import private.asc
```

<Image src={ss3} alt="Screenshot 3" caption="Зураг 3: GPG key импорт хийх үеийн гаралт" />

Key жагсаалтыг харвал.

<Image src={ss5} alt="Screenshot 5" caption="Зураг 5: Дэкрипт хийсэн тугийн агуулга" />

```bash
gpg -d flag.pgp
```
